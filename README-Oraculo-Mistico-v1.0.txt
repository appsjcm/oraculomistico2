Oráculo Místico v1.0

App PWA simbólica con tarot, runas, luna, sueños, numerología, Grabovoi, diario místico, voz, avatar animado, PDF premium y Chat Ritual.

Voz:
- Por defecto utiliza el TTS del sistema, sin Puter.
- Puede mostrar todas las voces que el navegador permita consultar.
- Las voces disponibles pueden variar entre Firefox, Chrome, Safari, iPhone y Android.

Publicación rápida:
1. Descomprime el ZIP.
2. Sube todo el contenido a GitHub Pages.
3. Abre la URL pública.
4. Comprueba una lectura, la voz, el avatar y la instalación desde un móvil.

Uso simbólico y de entretenimiento. No sustituye consejo profesional.

Privacidad:
- El perfil, diario, preferencias y chat se guardan localmente en el navegador.
- Al conectar Puter IA, el texto enviado a la IA se procesa mediante Puter.
- Si el chat no encuentra un número Grabovoi en el manual, puede consultar fuentes públicas y lo identifica expresamente como resultado externo.
- Las cartas, algunas runas, Puter IA y jsPDF dependen de recursos externos.
- Revisa privacy.html antes de publicar e incorpora una dirección de contacto si procede.
